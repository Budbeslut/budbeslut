# Budbeslut

AI-driven due diligence för bostadsrätter.

## Vision

Hjälpa bostadsköpare fatta bättre beslut innan budgivning.

## MVP

Input:
- Adress
- Kvm
- Pris
- Avgift
- BRF-skuld/kvm

Output:
- Lägespoäng
- Bostadspoäng
- BRF-poäng
- Prispoäng
- Totalpoäng
